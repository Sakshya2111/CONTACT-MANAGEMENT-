Contact Management System

A simple and user-friendly Contact Management System designed to help users store, manage, and organize their contact information efficiently. The application allows users to add, view, search, update, and delete contacts from a centralized system.

🚀 Features
👤 Add new contacts
📋 View all saved contacts
🔍 Search contacts quickly
✏️ Update existing contact details
🗑️ Delete contacts
📞 Store phone numbers and email addresses
🏠 Store address and other contact information
💾 Manage contact records efficiently

🎯 Purpose

The main purpose of this project is to provide an efficient digital solution for managing contact information. It eliminates the need for maintaining contacts manually and makes accessing and updating information faster and easier.
